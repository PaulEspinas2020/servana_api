## Retirement criteria

An alias is deleted only when **all** of these hold. Written down because "we think
nobody calls it" is how `/api/services/:id/options-with-addons` came to 404 in production
for months — a path can look dead from the server and still be the only thing a shipped
build knows how to call.

- Web-only alias: **14 consecutive days** of zero recorded hits.
- Mobile alias: **90 consecutive days** of zero recorded hits — the installed base has to move, not just the current build.
- Every client the matrix lists for the route reads `migrated`: **true**.
- The canonical successor is `implemented`, not `planned`: **true**.

Measure with: `pm2 logs servana-prod | grep legacy-contract`.
